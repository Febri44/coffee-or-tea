# coffee-or-tea

Exactly one letter, A for coffee, written to `/output/entry.txt` by `main.ts`
(Node 22). Built for the make.fun bounty
[One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

## Run

```sh
node main.ts
```

It writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
